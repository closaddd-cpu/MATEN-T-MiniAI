# MATEN/T MiniAI v1 — کوردی

**BY MATEN/T · M/ License v1.0**

پڕۆژەیەکی کراوەی فێرکارییە بۆ ڕاهێنانی مۆدێلی AI لە سفرەوە: **86,019,712 پارامێتر، 2,048 context token، tokenizer ـی 16,384** و Chat UI ـی تاریک/ڕوون.

**داتاسێت:** 50 زمانی پڕۆگرامسازی، 20 زمانی مرۆیی (کوردی سۆرانی، کورمانجی، ئینگلیزی، عەرەبی و 16 زمانی دیکە)، 24 بابەتی زانستی و گفتوگۆ. کۆی گشتی **94 فایل × 100,000 ڕیز = 9,400,000 ڕیز**.

⚠️ **گرنگ:** 9.4 ملیۆن نموونەی *synthetic* هەمان 9.4 ملیۆن پرسیاری دەستنووسی کوالێتی بەرز نییە. زۆرێکیان لە هەمان نموونە بە ژمارەی جیاواز دروست بوون. ئەمە تەنها دەستپێکێکی ئەندازیاری و ڕاهێنانە، نە مۆدێلێکی تەواو ڕاهێنراو یان زانای 20 زمان. ڕاهێنانی تەواو بە GPU و داتای ڕاستەقینەی کوالێتی بەرز پێویستە.

## کارپێکردن

```sh
python -m pip install -r requirements.txt
python miniai.py info
python -m unittest discover -s tests -v
```

بۆ دروستکردنی داتا لە ZIP ـی کۆد تەنها:

```sh
python build_datasets.py --count 100000
python miniai.py prepare --samples-per-domain 1000
```

بۆ ڕاهێنانی نموونەی 86M:

```sh
python miniai.py train --device auto --epochs 1 --batch-size 1 --grad-accum 8 --sequence-length 256
```

بۆ ڕاهێنانی بە 2K Context ئەگەر GPU توانای هەبێت، `--sequence-length 2048` هەڵبژێرە. بۆ وێبسایتی چات، دوای ڕاهێنان:

```sh
python miniai.py serve
```

بچۆ بۆ `http://127.0.0.1:8765`. هەڵبژاردەی 20 زمان بۆ وەڵام هەیە، بەڵام ئامادەیی زمان بە مۆدێلی ڕاهێنراوەوە پەیوەستە. فایلەکانی `.bat` بەکارنەهاتوون. ناوی کارتی گرافیکی تایبەتی هیچ کەسێک لە ڕێنمایی پێویست نییە. لایسەنسی M/ تەنها مافی ئەو شتانە دەدات کە MATEN/T مافیان هەیە.

## ڕاهێنانی FP16 — BY MATEN/T

لە CUDA GPU ـی گونجاودا `--precision fp16` بە شێوەی mixed precision بەکاردێت (autocast + GradScaler). لە CPU بە `--precision auto` سیستەم بە FP32 کاردەکات؛ هیچ بانگەشەیەک نییە بۆ FP16 لە CPU. Warmup و cosine learning-rate schedule زیادکراون بۆ جێگیری باشتر؛ ئەمە بەڵێنی مۆدێلی زاناتر نییە هەتا ڕاهێنانی ڕاستەقینە ئەنجام بدرێت.

```sh
python miniai.py train --device cuda --precision fp16 --batch-size 1 --grad-accum 8 --sequence-length 256 --max-steps 1000
```

لابردنی نووسینی پێویستی MATEN/T لە فایلە سەرەکییەکان هەڵەی ڕوون پیشان دەدات؛ ئەمە پاراستنی تەواوی کۆدی ئاشکرا نییە.
