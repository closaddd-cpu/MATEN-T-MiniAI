KURDISH SORANI — ڕێنمایی ڕاهێنانی مۆدێل لەسەر PC
========================================================================

١) ئەم پڕۆژەیە چییە؟
MATEN/T MiniAI v1 مۆدێلێکی زمانی Decoder Transformer ـە بە 86,019,712
پارامێتر، context ـی 2,048 token و tokenizer ـی 16,384 token.
ئەم GitHub ـە کۆدی ڕاهێنان و دروستکردنی داتا دەدات؛ مۆدێلی تەواو
ڕاهێنراوی باش و فایلی tokenizer.model لە GitHub ـەکەدا نییە.
ڕاهێنان لە سفرەوەیە. داتای synthetic ـی دروستکراو گەرەنتی شارەزایی
لە کوردی، کۆدنوسین، زانست و سایبەر نادات.

٢) چ PC ـێک باشە؟ (ڕێنمایی نزیکەیی، نە گەرەنتی)

- تاقیکردنەوەی بچووک: CPU ـی 4–6 core، RAM ـی 16GB،
  و چەند GB شوێنی بەتاڵ. --tiny بۆ test ـە، نە مۆدێلی 86M.
- دەستپێکی ڕاهێنانی 86M: CPU ـی 6 core یان زیاتر،
  RAM ـی 16–32GB، GPU ـی NVIDIA و 8–12GB VRAM؛
  batch-size 1 و sequence-length 128/256 تاقی بکەرەوە.
  8GB لە هەموو سیستەمێکدا کارکردن گەرەنتی نییە.
- PC ـی پێشنیارکراو: 6–12 core CPU، RAM ـی 32GB،
  GPU ـی CUDA ـپشتگیریکراو بە 16–24GB VRAM،
  NVMe SSD و هەوای ساردکردنەوەی باش.
- بۆ تاقیکردنەوەی context ـی 2048: 24GB VRAM یان زیاتر
  پێشنیار دەکرێت؛ بەڵام بیرگەی پێویست بە شێوازی کۆد،
  batch-size و PyTorch پەیوەستە و لەوانەیە زۆرتر پێویست بێت.
- Disk: 20GB+ بۆ دەستپێک؛ 50GB+ بۆ داتا و checkpoint ـە گەورەکان
  باشترە. RAM و VRAM جیاوازن.
- CPU-only ـیش دەکرێت، بەڵام ڕاهێنانی 86M لەسەر ملیۆنان ڕیز
  لەوانەیە زۆر خاو بێت. هێزی پاوەر و گەرمی GPU گرنگن.
- AMD GPU: تەنها لە سیستەمی ROCm/PyTorch ـی بەڕاستی پشتگیریکراو
  بەکار دەچێت. GPU ـی هەر کامپیوتەرێک خۆکار خێرا نابێت.
  macOS MPS هەڵبژاردەیەکە، بەڵام ئەم کۆدە auto ـدا FP32 دەکات.
- NVIDIA CUDA بەهێز و پشتگیریکراو ئاسانترین ڕێگای FP16 ـە.

٣) دابەزاندن و ئامادەکردن
Python 3.10+ دابنێ. لە terminal ـی ناو فۆڵدەری پڕۆژەکە:

  python -m venv .venv

Windows PowerShell:
  .venv\Scripts\Activate.ps1
Linux / macOS:
  source .venv/bin/activate

PyTorch ـی گونجاو بۆ OS/GPU ـەکەت لەم لینکە هەڵبژێرە:
  https://pytorch.org/get-started/locally/
پاشان:
  python -m pip install -r requirements.txt
  python miniai.py info
  python -c "import torch; print('GPU:', torch.cuda.is_available(), 'CUDA:', torch.version.cuda, 'ROCm:', torch.version.hip)"

ئەگەر GPU: False بوو، بە GPU ـی CUDA کار ناکات. بە درۆ
مەڵێ ڕاهێنان بە GPU ـە؛ --device cpu بەکاربهێنە.

٤) تاقیکردنەوەی خێرا (بە داتای کەم و مۆدێلی --tiny)
  python build_datasets.py --count 1000 --domains kurdish_sorani english python cybersecurity
  python miniai.py prepare --domains kurdish_sorani english python cybersecurity --samples-per-domain 500
  python miniai.py train --tiny --device auto --precision auto --domains kurdish_sorani english python cybersecurity --sequence-length 64 --batch-size 1 --grad-accum 2 --limit-samples 128 --max-steps 2 --save-every 1 --eval-batch-size 1 --output checkpoints-smoke

ئەمە تەنها پشکنینی pipeline ـە؛ مۆدێلی 86M نییە.

٥) ئامادەکردنی داتای تەواو و tokenizer
  python build_datasets.py --count 100000
  python miniai.py prepare --samples-per-domain 1000

ئەم کارە 94 فایلی JSONL ـی synthetic دروست دەکات.
Tokenizer ـەکە دوای دەستپێکردنی ڕاهێنانی ڕاستەقینە
مەگۆڕە، چونکە checkpoint ـی پێشوو لەوانەیە ناسازگار ببێت.
Checkpoint ـی --tiny بۆ مۆدێلی 86M بەکار مەهێنە.

٦) ڕاهێنانی مۆدێلی ڕاستەقینەی 86M — CUDA / FP16
  python miniai.py train --device cuda --precision fp16 --epochs 1 --batch-size 1 --grad-accum 8 --sequence-length 256 --max-steps 100 --save-every 25 --warmup-steps 10 --lr-decay-steps 100

ئەمە تەنها 100 optimizer step ـە بۆ دەستپێک؛
ڕاهێنانی تەواوی هەموو داتاسێت نییە.
FP16 mixed precision ـە: forward بە precision ـی تێکەڵ،
وزن و optimizer state ـکان بە FP32 دەمێننەوە.
FP16 خۆی مۆدێل زاناتر ناکات؛ تەنها دەتوانێت ڕاهێنان
لەسەر هاردوێری گونجاو چاکتر/خێراتر بکات.

٧) لەسەر CPU (بێ CUDA)
  python miniai.py train --device cpu --precision fp32 --epochs 1 --batch-size 1 --grad-accum 8 --sequence-length 128 --max-steps 20 --save-every 10 --warmup-steps 5 --lr-decay-steps 100

٨) ئەگەر کارەکە وەستا — Resume
لە ڕاهێناندا فایلەکان لە checkpoints/last.pt دەپارێزرێن.
ئەگەر PC کوژایەوە، تەنها لە دوایین checkpoint دەست پێ دەکاتەوە.
هەمان dataset domains، batch-size، grad-accum، sequence-length،
learning rate و schedule بەکاربهێنە؛ بەڵام max-steps زیاد بکە.

  python miniai.py train --device cuda --precision fp16 --epochs 1 --batch-size 1 --grad-accum 8 --sequence-length 256 --max-steps 200 --save-every 25 --warmup-steps 10 --lr-decay-steps 100 --resume checkpoints/last.pt

ئەگەر epoch تەواو بووبێت، --epochs بۆ ژمارەیەکی
گەورەتر زیاد بکە. checkpoint ـی نەناسراو بەکار مەهێنە،
چونکە PyTorch checkpoint تەنها لە سەرچاوەی متمانەپێکراو
دەبێت load بکرێت.

٩) کاتێک VRAM کەمە
- --batch-size 1 دابنێ.
- --sequence-length لە 2048 بۆ 256، 128 یان 64 کەم بکە.
- --grad-accum 8 یان 16 هەڵبژێرە (بۆ گۆڕانی effective batch).
- --eval-batch-size 1 بەکاربهێنە.
- بەرنامە GPU ـخۆرەکانی تر دابخە.
- --sequence-length 256 واتە ڕاهێنان لەسەر 256 token؛
  context capacity ـی 2048 لە model.py ناگۆڕێت.
- ئەگەر CUDA OOM بوو، settings ـەکان کەم بکەوە.
  ئەگەر NaN/loss ـی ناجێگیر بینرا، FP32 تاقی بکەرەوە
  و learning rate کەم بکە.

١٠) هەڵسەنگاندن و چات
  python miniai.py evaluate --checkpoint checkpoints/last.pt --split validation --max-batches 20 --precision auto
  python miniai.py serve --device auto --port 8765

Browser: http://127.0.0.1:8765
تەنها دوای ڕاهێنان Chat UI بەکاربێنە.
Loss ـی validation و نموونەی گفتوگۆ هەردووکیان تاقی بکەرەوە.
ئامانجی پڕۆژەکە دروستکردنی AI ـێکی زەبەلاحە؛ داتا و زمانەکان
پێویستیان بە پشکنینی مرۆڤ و benchmark ـی سەربەخۆ هەیە.

========================================================================
ENGLISH — HOW TO TRAIN MATEN/T MINIAI ON YOUR OWN COMPUTER
========================================================================

PROJECT: ~86M trainable parameters; 2,048-token maximum context;
16,384 SentencePiece vocabulary; 94 procedurally generated JSONL shards.
This repository provides the architecture and training code, not trained
production weights or a bundled pretrained tokenizer.

RECOMMENDED SYSTEM (GUIDANCE, NOT A GUARANTEED REQUIREMENT)
- Smoke tests: 4–6-core CPU, 16 GB RAM, SSD; use --tiny.
- Entry GPU: supported NVIDIA CUDA card with approximately 8–12 GB
  VRAM; start with 128/256 training tokens and microbatch 1.
- More comfortable: 6–12-core CPU, 32 GB RAM, NVIDIA CUDA GPU with
  16–24 GB VRAM, SSD, cooling and adequate power supply.
- Longer 2,048-token sequences: consider 24 GB+ VRAM; actual usage
  varies and cannot be promised without measuring your setup.
- Disk: allow 20 GB or more; 50 GB+ is more practical for datasets,
  tokenizer creation, logs and repeated optimizer checkpoints.
- CPU-only is supported but very slow for long 86M training runs.
- GPU support requires a compatible PyTorch build and driver. Check
  AMD ROCm support for your exact operating system/card; not all
  AMD GPUs or Windows configurations will work. Apple MPS uses FP32
  in this project's current precision selector. CUDA FP16 is tested
  only on systems with an actually compatible CUDA stack.

INSTALL
  python -m venv .venv
  # Windows PowerShell: .venv\Scripts\Activate.ps1
  # Linux/macOS: source .venv/bin/activate
  # Select the appropriate PyTorch installation at:
  # https://pytorch.org/get-started/locally/
  python -m pip install -r requirements.txt
  python miniai.py info
  python -c "import torch; print(torch.cuda.is_available(),torch.version.cuda,torch.version.hip)"

CREATE DATA + TOKENIZER (from source checkout)
  python build_datasets.py --count 100000
  python miniai.py prepare --samples-per-domain 1000

A SMALL TEST BEFORE EXPENSIVE GPU TRAINING
  python miniai.py train --tiny --device auto --precision auto --sequence-length 64 --batch-size 1 --grad-accum 2 --limit-samples 128 --max-steps 2 --output checkpoints-smoke

REAL ~86M TRAINING WITH CUDA FP16
  python miniai.py train --device cuda --precision fp16 --batch-size 1 --grad-accum 8 --sequence-length 256 --max-steps 100 --save-every 25 --warmup-steps 10 --lr-decay-steps 100

RESUME AFTER INTERRUPTION
  python miniai.py train --device cuda --precision fp16 --batch-size 1 --grad-accum 8 --sequence-length 256 --max-steps 200 --save-every 25 --warmup-steps 10 --lr-decay-steps 100 --resume checkpoints/last.pt

For CPU, substitute --device cpu --precision fp32 and reduce sequence
length/step count. Matching tokenizer, architecture, data and optimizer
settings are required when resuming. Do not overwrite the tokenizer
mid-training, or mix --tiny weights with the 86M model.

TROUBLESHOOTING
- torch.cuda.is_available() == False: choose a supported PyTorch/driver
  combination, or use --device cpu. CUDA FP16 is not available otherwise.
- CUDA out of memory: microbatch=1, reduce sequence length, set
  --eval-batch-size 1, close other GPU-intensive apps.
- Interrupted process: restart from the most recent trusted
  checkpoints/last.pt; progress after the most recent save is lost.
- Loss becomes NaN/Inf: inspect data, reduce LR, or try FP32.
- Chat says nonsense: training a randomly initialized small model is
  not the same as fine-tuning a pretrained assistant.
- If Python packages conflict: use a fresh virtual environment.
- If training every shard is too large, choose one or more domains
  consistently with --domains (and generate those shards first).

POST-TRAINING
  python miniai.py evaluate --split validation --checkpoint checkpoints/last.pt --max-batches 20
  python miniai.py serve --device auto --port 8765
  # Browse: http://127.0.0.1:8765

COLAB: Use notebooks/MATEN-T-MiniAI-v1-Colab.ipynb and store training
checkpoints on persistent Google Drive. A free session may disconnect
before a full dataset epoch finishes.

IMPORTANT HONESTY NOTES:
- FP16 is automatic mixed precision, not FP16 storage of all weights.
- FP16 alone does not make a model smarter; training data, evaluation,
  total tokens and sufficient optimization are what matter.
- Synthetic rows generated from templates are not equivalent to
  expert-reviewed conversational data.
- Source attribution is required by M/ License. brand_guard.py checks
  attribution in standard entrypoints but is not unbreakable DRM.
- This project does not include any .bat installer or hidden downloader.
